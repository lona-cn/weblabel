## 本任务验收命令

T00完成后统一入口：`pnpm test:task T15`。它必须实际执行：

```text
pnpm exec playwright test tests/e2e/t15_vertical.spec.ts --project=chromium-webgpu
pnpm exec vitest run tests/integration/t15_exports.test.ts
```

还必须通过受影响语言的格式、类型和contract检查。以下情况均不算通过：测试命令不存在、匹配0条测试、对应provider未启用，或测试全部skip。统一入口由T00先实现，再调用；不能形成递归。
