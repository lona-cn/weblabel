# T31 · 目标机器真实WebGPU与性能验收

在目标机器上验证真实 WebGPU、资源生命周期和固定数据量下的性能目标。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-qa`。**前置:** T30。**互斥域:** hardware-evidence。
**外部实测关卡:** 是。环境不满足时必须标blocked，不能用mock替代实测。

## 验收时逐项检查

1. actual WebGPU设备不能是canvasmock。softwareadapter不能通过hardware gate。
2. 记录OS/CPU/GPU/driver/browser/commit/DPR及target尺寸。无法读取的值标unknown。
3. 2000boxes预热后收集≥1000样本。P95CPU≤8ms、pointer-to-next-frame≤33ms目标都必须有实测。
4. 100次切图资源统计稳定。在真实浏览器中验证0尺寸和device loss恢复。
5. 压测失败不能降低数据量，也不能换高配机器后隐瞒原基线。

## 怎样实施

- [ ] 开始前核对depends_on：所有依赖都应已done，且对应commit已经集成。再检查文件范围，确保可写路径不与其他在途任务重叠。

- [ ] 运行真实targetprofile。没有GPU时非零退出并标blocked，保留可执行命令；不依赖它的其他任务继续。
- [ ] pointer-to-frame若只能测CPU调度到rAF，必须标明是代理指标，不是真实屏幕光子延迟。

- [ ] perf阈值失败时先保留报告，再交T28定位。QA不能修改benchmark掩盖失败。
