# T08 · React工作台外壳与虚拟对象列表

实现工作台页面和虚拟对象列表，让用户能通过键盘和属性控件操作大量对象。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 对象数为10000时，DOM行数仍受viewport限制，不能创建10000元素。
2. 按属性schema动态生成控件。未知属性值必须显示错误。
3. 键盘能聚焦控件，按钮有accessible name，长中文类别不能遮挡画布。
4. 明确区分loading/error/empty/unsupported。任何mock都必须显示DEV MOCK徽标。
