## 必须验证的行为

1. 对象数10000时DOM行数受viewport限制，不创建10000元素

```tsx
import {render,screen} from '@testing-library/react';
import {expect,it} from 'vitest';
import {ObjectList} from './ObjectList';
it('renders accessible empty state',()=>{
 render(<ObjectList objects={[]} selectedIds={[]} onSelect={()=>{}} />);
 expect(screen.getByTestId('object-list')).toBeDefined();
 expect(screen.getByText('暂无标注对象')).toBeDefined();
});
```
