## 必须验证的行为

1. 批准图像hash/profile/crop后任一改变，原consent无效；非外发检测无需云授权但权重下载需授权
2. 发起AI前等待flush成功，冲突或本地未持久化阻止基于错误版本运行
3. raw prediction与正式annotation隔离；accepted decision与revision同事务
4. mock工程演示明确标记；真实profile不可连fake process或返回固定JSON
5. 取消/超时/额度/模型不存在无自动重试计费，无context换图错写

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```ts
import {expect,it} from 'vitest';
import {matchesConsent} from '../../apps/web/src/features/ai/runCoordinator';
it('invalidates consent when input fingerprint changes',()=>{
 expect(matchesConsent({approved_fingerprint:'sha-A'}, {input_fingerprint:'sha-B'})).toBe(false);
 expect(matchesConsent({approved_fingerprint:'sha-A'}, {input_fingerprint:'sha-A'})).toBe(true);
});
// 同文件必须通过真实HTTP重复该检查，UI断言不能替代服务端授权。

```
