## 行为验收

1. 持久 SQLite 旧 profile/snapshot/run 保留原身份；list 不提供退役 profile，其他 profile 正常。
2. 新 preview/start 在既有项目/context 检查顺序内返回 409 `PROVIDER_RETIRED`，不创建 preview/consent/run/job。
3. 同 operation 同 payload 回放原 run；换 payload 仍 409。不重执行历史结果。
4. 旧 queued Codex 在调用任何 runner 前走既有 failed terminal 事务；取消优先，模型执行次数 0。
5. ProductionRunner 与 Host 实值配置在 token/context/进程创建前拒绝退役选择；真实子进程无模型执行和候选。
6. 历史 GET、prediction/decision、撤销与旧幂等回执仍可解码；不改 migration/CHECK 或 profile/run/model identity。
7. UI 不选退役 profile、不自动改选另一个模型；缓存退役选择不可运行，Consent 不提供确认控件。
8. 安全专题本轮 `skipped_by_user/not_verified`；只清退 T29 的已删除 Codex 专属 import/case，泛化业务 fixture 换为活动等价来源，不执行 T29。
