## 必须验证的行为

1. EXIF1..8不对称彩色角图，镜像也正确；输出PNG不残留旋转标签
2. 64MiB、4096边长、像素上限分别拒绝；伪MIME/截断/多帧/CMYK不静默接受
3. 同名不同图保留不同ID，Unicode/空格路径合法，超长命名明确错误
4. 作业单项失败不丢其他成功项；重复请求可识别；原文件不可变

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```rust
#[test]
fn canonical_corner_fixture_has_known_dimensions() {
 let im=image::load_from_memory(include_bytes!("../../../tests/fixtures/media/orientation-6.jpg")).unwrap();
 // canonicalize_bytes由本任务实现，返回canonical RGBA、方向及矩阵。
 let c=weblabel_api::media::canonical::canonicalize_bytes(include_bytes!("../../../tests/fixtures/media/orientation-6.jpg")).unwrap();
 assert_eq!((c.width,c.height),(im.height(),im.width()));
 assert_eq!(c.original_to_canonical.len(),9);
}
```
