## 必须验证的行为

1. C8精确向量；DPR1/1.25/2/3均相同图像坐标
2. 随机scale0.01..64及平移的往返误差≤1e-8；scale0/负/NaN拒绝
3. 边/角容差6CSSpx随zoom换算；矩形边界半开/连续坐标不+1
4. 空间索引更新/删除后结果等于朴素扫描；重叠排序稳定且可循环

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```rust
use geometry::{Viewport,image_to_css,css_to_image};
#[test]
fn dpr_is_not_annotation_scale() {
 for dpr in [1.0,1.25,2.0,3.0] {
  let v=Viewport{scale:2.0,tx:13.0,ty:-7.0,css_width:800.0,css_height:600.0,dpr};
  assert_eq!(image_to_css([10.0,20.0],v),[33.0,33.0]);
  assert_eq!(css_to_image([33.0,33.0],v),[10.0,20.0]);
 }
}
```
