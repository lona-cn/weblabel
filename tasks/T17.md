## 必须验证的行为

1. 同operation_id相同输入不创建第二计费运行；不同payload409
2. 乱序/重复provider事件规范化seq，终态不可回running
3. cancel之后返回候选可存隔离审计但不可应用或自动继续
4. 重启遗留running标interrupted，费用可能已发生显示unknown，不自动重发
5. 单图失败不把整批成功项丢失，API所有路径验证project

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```rust
use weblabel_api::ai::runs::{RunState,transition};
#[test]
fn terminal_run_cannot_restart_from_late_event(){
 assert!(transition(RunState::Cancelled,RunState::Running).is_err());
 assert!(transition(RunState::Succeeded,RunState::Running).is_err());
 assert!(transition(RunState::Running,RunState::Succeeded).is_ok());
}
```
