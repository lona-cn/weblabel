# T20 · OpenAI/Luna、Anthropic与MiMo HTTP适配器

分别实现模型 HTTP 适配器，按官方协议处理图像、工具调用、错误和外发限制。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-ai`。**前置:** T16。**互斥域:** http-providers。
**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 图像payload、角色格式和stream/tool结构分别遵循对应provider。不能将一个OpenAI兼容模板套用到全部渠道。
2. 401/403/429/5xx/timeout/invalidJSON、超大结果和中断事件都要有明确错误。
3. 工具多轮调用必须受回合、字节和时间预算限制。不支持structured_output时，解析候选仍须经过schema+domain严格校验。
4. 未知usage/cost=null，禁止显示0元。超时不能自动重复POST。
5. 修改API base必须人工配置或批准。防止SSRF、redirect到内网和authorization泄漏。

- [ ] HTTPclient只允许官方域名。私有endpoint只能由受信任本地管理员配置，默认拒绝任意URL。
- [ ] 每个adapter先写官方协议fixture测试。模型ID经配置或探测后完整展示，不能凭名字猜能力。
- [ ] 明确区分全图和对象crop输入，并附canonical变换。token/pixel预算与privacy fingerprint必须一致。
- [ ] Luna使用本账号可用的官方完整ID。未获得MiMo合同则对应子项blocked，不能用其他渠道返回替代。
- [ ] 禁止第三方API-key进入浏览器、localStorage或dataset文件。日志必须脱敏。
- [ ] 实现后复跑下面全部检查，保存完整输出、退出码、测试数和运行环境。不得为了通过而降低阈值、删除反例或注入固定成功响应。
