## 必须验证的行为

1. 图像payload/角色格式/stream/tool结构按该provider，不用一个OpenAI兼容模板套全部
2. 401/403/429/5xx/timeout/invalidJSON/超大结果/中断事件各有明确错误
3. 工具多轮有回合/字节/时间预算；不支持structured_output时解析候选仍经schema+domain严格校验
4. 未知usage/cost=null，禁止显示0元；超时不自动重复POST
5. 不同API base修改需人工配置/批准，防SSRF/redirect到内网或泄漏authorization

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```ts
import {expect,it} from 'vitest';
import {normalizeUsage} from '../src/providers/http/usage';
it('does not invent a price when absent',()=>{
 const u=normalizeUsage({input_tokens:120,output_tokens:20});
 expect(u.input_tokens).toBe(120);
 expect(u.cost_usd).toBeNull();
});
```
