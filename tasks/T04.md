## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```rust
use annotation_domain::{AnnotationDocument,OntologyVersion,EditorCommand};
use editor_core::Editor;
#[test]
fn empty_undo_preserves_document() {
 let d:AnnotationDocument=serde_json::from_str(include_str!("../../../tests/fixtures/golden/document.json")).unwrap();
 let o:OntologyVersion=serde_json::from_str(include_str!("../../../tests/fixtures/golden/ontology.json")).unwrap();
 let mut e=Editor::new(d,o).unwrap();
 let before=serde_json::to_value(e.snapshot()).unwrap();
 let delta=e.dispatch(EditorCommand::Undo).unwrap();
 assert!(!delta.document_changed);
 assert_eq!(serde_json::to_value(e.snapshot()).unwrap(),before);
}
```
