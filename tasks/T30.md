## 验收时逐项检查

1. assetB打开后runA返回，结果只能出现在A。旧suggestion不能覆盖新属性。
2. 8ACK晚于9edit、服务失败或localquota错误时，都能恢复或导出草稿。
3. 验证两标签页下CAS和lease组合。进程crash不能留下半写revision或错误的已保存状态。
4. GPUlost后CPUdoc hash不变且能重建。不能靠刷新整应用、丢掉未保存数据来解决。
5. 导出断开后重试仍读取原snapshot。模型超时费用记unknown，不能自动重发。

```ts
import {test,expect} from './fixtures';
test('network failure never becomes server-saved',async({adminPage:page})=>{
 await page.route('**/api/assets/*/annotation',async route=>{
  if(route.request().method()==='PUT') await route.abort('failed'); else await route.continue();
 });
 await page.getByTestId('attribute-helmet_state').selectOption('wearing');
 await expect(page.getByTestId('save-status')).not.toContainText('已同步到服务器');
 await expect(page.getByTestId('export-local-draft')).toBeVisible();
});
```
