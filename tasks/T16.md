# T16 · 安全Agent Host、进程监管与provider抽象

建立受限 Agent Host、进程监管和 provider 抽象，隔离模型故障与人工编辑。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-ai`。**前置:** T01, T02, T10。**互斥域:** agent-host-core, runtime-protocol。
**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 逐行截断、多行、超过4MiB、未知method和重复ID都必须可控失败。
2. child crash、超时或取消后，必须收回子孙进程，且不影响手工编辑。
3. 启动使用shell:false、受信任可执行路径、独立argv、白名单env和受限cwd。空格及中文路径必须正确处理。
4. 日志必须去除密钥、cookie、authorization和图片字节。不得将整个process.env传给子进程。

## 测试样例与断言

下面给出核心测试的输入和断言起点，不能替代完整验收。优先复用公共测试fixture。若需要新helper，应在本任务内实现，并写明精确类型。

JSON块描述测试条件，不是运行结果。代码片段中的场景变量，需要按前述步骤在测试Arrange段准备。最终必须验证实际行为，不能用注释或静态常量检查代替。

```ts
import {expect,it} from 'vitest';
import {parseEnvelope} from '../src/protocol';
it('rejects oversized messages before JSON decode',()=>{
 expect(()=>parseEnvelope('x'.repeat(4*1024*1024+1))).toThrow(/message_too_large/);
});
it('rejects a mismatched protocol',()=>{
 expect(()=>parseEnvelope(JSON.stringify({protocol_version:99,id:'x',kind:'request',method:'probe',payload:{}}))).toThrow(/protocol_version/);
});
```

- [ ] 开始前核对depends_on：所有依赖都应已done，且对应commit已经集成。再检查文件范围，确保可写路径不与其他在途任务重叠。

- [ ] Host stdout只输出协议，日志写stderr。启动握手校验protocol_version=1。
- [ ] 运行所有者及暂存grant绑定run/project/media hash。路径规范化后必须位于root内，拒绝symlink/junction逃逸。
- [ ] 先实现fake-runtime和错误测试，再真实spawn。检测并测试Windows进程树清理方案，不能依赖POSIX-only信号。
- [ ] probe分别暴露availability和verification。mock只在测试build中注册。
- [ ] model-profiles只含配置别名和secret ref，不含token。禁止自动重复重试计费请求。
- [ ] 实现后复跑下面全部检查，保存完整输出、退出码、测试数和运行环境。不得为了通过而降低阈值、删除反例或注入固定成功响应。
- [ ] 提交规格审查和质量/安全审查。按实际diff修复问题，改动应尽量小；修复后由主Agent复跑目标测试。
