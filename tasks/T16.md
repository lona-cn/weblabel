## 必须验证的行为

1. 逐行截断/多行/4MiB上限/未知method/重复ID可控失败
2. child crash/超时/取消后子孙进程收回，手工编辑不受影响
3. shell:false、受信任可执行路径、独立argv、白名单env、受限cwd；路径空格/中文正确
4. 日志完全去除密钥、cookie、authorization和图片字节；不得把整个process.env传子进程

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```ts
import {expect,it} from 'vitest';
import {parseEnvelope} from '../src/protocol';
it('rejects oversized messages before JSON decode',()=>{
 expect(()=>parseEnvelope('x'.repeat(4*1024*1024+1))).toThrow(/message_too_large/);
});
it('rejects a mismatched protocol',()=>{
 expect(()=>parseEnvelope(JSON.stringify({protocol_version:99,id:'x',kind:'request',method:'probe',payload:{}}))).toThrow(/protocol_version/);
});
```
