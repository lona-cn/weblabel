## 必须验证的行为

1. token过期/撤销/错误project不能读取图或对象；sessioncookie不能代替run token
2. read_region坐标/数量/像素预算受限；不给任意磁盘路径或URL
3. propose_changes不直接保存正式标注，拒绝accept/delete_file/shell等未知工具
4. 图片/类别/规范中的提示注入无法拓展权限；工具参数带projectID拒绝
5. 分页、重复调用、输入过大、空工具结果序列可恢复

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```ts
import {expect,it} from 'vitest';
import {TOOL_NAMES,validateToolArgs} from '../src/mcp/tools';
it('contains no write-through or arbitrary execution tool',()=>{
 expect([...TOOL_NAMES].sort()).toEqual(['get_context','list_objects','propose_changes','read_region','report_issues']);
 expect(()=>validateToolArgs('read_region',{region:null,path:'C:\Users\secret.txt'})).toThrow();
});
```
