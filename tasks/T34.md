## 必须验证的行为

1. 失焦/空闲超过60秒不计有效工时，时钟倒退/重载不产生负耗时
2. 模型等待与人工操作分开，模型费用unknown保持null
3. 纯人工/现有工具同AI/本工具同AI对照字段齐全；漏标包括AI未提出对象
4. 未进行真实试点不输出“节省30%”或自动结论，样本量0报告无数据
5. 统计默认本地/项目内，自愿开启，不后台外传遥测

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```ts
import {expect,it} from 'vitest';
import {activeDuration} from '../../apps/web/src/features/workbench/activity';
it('does not count background time',()=>{
 expect(activeDuration([{start_ms:0,end_ms:1000,focused:true},{start_ms:1000,end_ms:9000,focused:false}])).toBe(1000);
});
```
