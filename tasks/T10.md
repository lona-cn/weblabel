# T10 · 本地认证、项目角色和不可变标注规范

实现本地登录、项目权限和不可变标注规范，守住媒体与写入的服务端授权边界。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-backend`。**前置:** T06。**互斥域:** backend-auth, project-api。
**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 开始前要确认什么

**先读：** `AGENTS.md`、`docs/architecture.md`、`docs/contracts.md`、`docs/testing-contracts.md`、`docs/execution.md`。主Agent应在派工时提供当前契约hash、base commit，以及依赖任务的证据。以这些材料为准，不依赖聊天记忆。

**依据：** C1/C2/C6、testing-contracts新增/users路由，以及loopback安全要求。

**交付内容：** 实现真实bootstrap/login/session/logout和admin用户创建。提供project四角色策略、ontology版本API及TestApp.as_user。

## 验收时逐项检查

1. bootstrap启动码必须一次性且会过期。明文密码不能出现在URL/log/cookie。
2. 无session返回401，wrongorigin返回403，viewer写入返回403；不能泄露跨项目资源。
3. 新ontology生成新ID，旧doc引用保留。unknown类别不能被偷偷创建。
4. 本地HTTP和HTTPS的cookie Secure行为必须符合显式配置。生产不得存在test bypass。
