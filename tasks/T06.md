## 必须验证的行为

1. 首次启动迁移及重启幂等；foreign_keys=ON/WAL生效
2. 相同哈希不可变内容去重，不把filename变为路径
3. 文件rename前故障无完成DB引用；DB故障最多留下孤儿文件
4. SQLite写入事务冲突有限超时，不阻塞请求线程做长推理

## 测试输入与断言起点

以下是核心测试输入/断言，不是全部验收。测试类任务使用已有公共测试fixture；需要新helper时同任务创建并给出精确类型。JSON块是测试条件，不是声称运行结果。片段中场景变量需按上文具体步骤在测试Arrange段创建，不能把注释或静态常量检查当最终行为测试。

```rust
#[tokio::test]
async fn sqlite_foreign_keys_are_enabled() {
 let pool=sqlx::SqlitePool::connect("sqlite::memory:").await.unwrap();
 sqlx::query("PRAGMA foreign_keys = ON").execute(&pool).await.unwrap();
 let (enabled,):(i64,)=sqlx::query_as("PRAGMA foreign_keys").fetch_one(&pool).await.unwrap();
 assert_eq!(enabled,1);
 // 同文件另测真实Repository::open，而非只验证SQLite自身。
}
```
