# T06 · SQLite、不可变文件仓库与服务器骨架

建立 SQLite、不可变对象存储与服务基础，保证故障时没有半完成的数据库引用。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 首次启动必须完成迁移，重启迁移保持幂等。确认foreign_keys=ON和WAL实际生效。
2. 相同哈希的不可变内容去重。filename不能直接变成存储路径。
3. 文件rename前故障不能留下完成状态的DB引用。DB故障最多留下孤儿文件。
4. SQLite写入事务冲突必须有有限超时。长推理不能阻塞请求线程。

```rust
#[tokio::test]
async fn sqlite_foreign_keys_are_enabled() {
 let pool=sqlx::SqlitePool::connect("sqlite::memory:").await.unwrap();
 sqlx::query("PRAGMA foreign_keys = ON").execute(&pool).await.unwrap();
 let (enabled,):(i64,)=sqlx::query_as("PRAGMA foreign_keys").fetch_one(&pool).await.unwrap();
 assert_eq!(enabled,1);
 // 同文件另测真实Repository::open，而非只验证SQLite自身。
}
```
