# T09 · WASM facade与浏览器画布生命周期

将 Rust 编辑与渲染能力接入 WASM facade，并正确管理浏览器画布生命周期。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-renderer`。**前置:** T04, T05, T08。**互斥域:** wasm, web-canvas。
**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 旧asset的异步init晚于新asset完成时，必须销毁旧实例，不能挂到新画布。
2. DPR、resize和CSSoffset计算正确。0×0时暂停；unmount清理listeners/rAF/device refs。
3. 一轮pointermove只传输入和小delta，不能调用get_snapshot或传全量JSON。
4. React StrictMode重复mount/unmount时不能产生双监听或双submit。

## 怎样实施

- [ ] 开始前核对depends_on：所有依赖都应已done，且对应commit已经集成。再检查文件范围，确保可写路径不与其他在途任务重叠。
- [ ] 为每条必验行为准备自动测试，或明确的真实硬件/账号探针。先运行本任务的窄命令，记录功能未实现时的实际失败。环境错误和未收集到测试都不算Red测试。
- [ ] 先明确canonical decode得到的图像已经没有EXIF。浏览器不能再次旋转；实测二进制接口的copybytes。
- [ ] 每个CanvasHost持有assetToken/disposeToken，异步创建前后都检查token。
- [ ] facade将Rust domain错误转换为结构化ApiError，不能panic成空白页。
- [ ] 用dirty flag调度render。resize、selection和资源加载可以触发渲染，idle时不能持续提交GPU。
- [ ] 实现后复跑下面全部检查，保存完整输出、退出码、测试数和运行环境。不得为了通过而降低阈值、删除反例或注入固定成功响应。
- [ ] 提交规格审查和质量/安全审查。按实际diff修复问题，改动应尽量小；修复后由主Agent复跑目标测试。
- [ ] 将commit和结构化结果交给主Agent，由主Agent按本卡范围集成并更新STATUS。子Agent不能自行标done。
