# T01 · 领域模型、共享契约、schema与黄金夹具

定义领域数据、共享协议和黄金夹具，使 Rust、WASM 与 TS 使用同一份契约。

这张卡是任务规格，不是当前通过声明。下列行为、验收命令和交付证据全部满足，并经审查与主 Agent 集成后，才算完成。

**负责角色：** `wl-core`。**前置:** T00。**互斥域:** contracts。
**外部实测关卡:** 否。若本任务包含真实外部调用，必须单独记录该子项的验证状态。

## 验收时逐项检查

1. 640×480黄金框必须能按规范序列化并往返恢复。显示flags不得进入文档。
2. 缺少必填属性、未知label、重复objectID、非有限数和错误尺寸都必须拒绝。
3. 所有显式null字段，以及save lease/suggestion_decisions，都必须与契约一致。
4. object_hash不受attributes键序影响，但bbox、label或属性改变时必须变化。预期哈希固定，并用独立canonical字符串核对。

下面给出核心测试的输入和断言起点，不能替代完整验收。优先复用公共测试fixture。若需要新helper，应在本任务内实现，并写明精确类型。

JSON块描述测试条件，不是运行结果。代码片段中的场景变量，需要按前述步骤在测试Arrange段准备。最终必须验证实际行为，不能用注释或静态常量检查代替。

```rust
use annotation_domain::{AnnotationDocument, OntologyVersion, validate_document};
#[test]
fn golden_document_validates_and_roundtrips() {
 let raw=include_str!("../../../tests/fixtures/golden/document.json");
 let doc: AnnotationDocument=serde_json::from_str(raw).unwrap();
 let ontology: OntologyVersion=serde_json::from_str(include_str!("../../../tests/fixtures/golden/ontology.json")).unwrap();
 assert!(validate_document(&doc,&ontology).is_ok());
 let back: AnnotationDocument=serde_json::from_str(&serde_json::to_string(&doc).unwrap()).unwrap();
 assert_eq!(serde_json::to_value(doc).unwrap(),serde_json::to_value(back).unwrap());
}
```
