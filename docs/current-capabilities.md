# 当前能力与适配边界

读者：产品负责人、标注负责人、运维与试用交付人员。读后行动：按当前源码和对应证据选择人工/审核/AI路径，不把实现、合成验收或历史发行当成商用保证。完整操作见[入门指南](getting-started.md)；已完成五批增量的原范围与验收依据仅在[体验计划归档](ux-improvement-plan.md)中保留，不是后续实施队列。

## 当前源码能力

| 范围 | 现行行为 | 证据与边界 |
|---|---|---|
| 人工检测标注 | 多类别 bbox、属性、批量兼容字段、输入草稿、连续类别、真实实时框预览、倍率与重叠命中 | 编辑几何只由 Rust Core 产生；连续 canonical xyxy 不加1、不持久化 DPR；需要真实 WebGPU |
| 保存与恢复 | CAS/幂等、lease/fence、真实本地与远端确认、分支只读差异和项目摘要 | 原请求/未知字段/历史作者保全；失败不称成功、不同 operation payload 不可借用旧回执 |
| 本机团队工作 | 账号/成员权限分层、本人/待审队列和分页、安全完成并继续 | 同一 loopback 服务多个本机身份；不是公网、SSO、远程实时协作或共识系统 |
| 审核 | 指定 immutable revision 的 canonical 图像、前后框/属性、全图及问题定位 | 默认禁止自审核；批准不会跟随新 head；只读 SVG 不冒充 GPU 编辑 |
| 导入与交付 | PNG/JPEG canonicalization；COCO/YOLO/native 标注预览、映射与损失；group-safe 划分和显式多批快照 | 每批 include+exclude<=1024；ZIP 96 MiB 独立预算；未浏览、未完成、未批准不会偷偷纳入 |
| AI 管理 | 管理员从服务器固定原生运行时预设建立不可变 profile，安全 hash/身份只读核对 | 不收 token/订阅代理；浏览器不提交 argv/endpoint/raw config；配置不等于 runtime、授权或模型验收 |
| AI 审校 | 可逐次收窄图像、固定对象详情与 canonical 整数 crop 的请求范围；显示真实服务端授权，候选只读对照、Native 显式采纳/撤销、持久逐项或整组拒绝；精确决策保存版本的提交审核关系、本人自愿明确关联的运行工时 | 无效或越界 crop 不改为整图；范围变化撤销旧预览和勾选，不从同图/后继版本猜任务；stale/异图/未经授权修改不能采纳；无关联记录/费用保持未知；记录不是准确率、完整工时、因果ROI或默认遥测 |
| 运维 | 分层 doctor、真实 SQL/对象根 readiness、实际容量与锁诊断、安全停机、只读升级预检、脱敏支持收据 | 依赖可读不是未来 I/O 或磁盘容量保证；AI 可选，不阻止人工准备；备份不包括浏览器未同步草稿 |

## 已观察与尚未承诺

本轮硬件渲染、事务、合成账号与实际 ZIP 证据按[报告索引](../reports/index.md)查找并核对源码绑定。1099项合成 workload 的审批通过公共 API，浏览器执行全部分页、两批冻结/下载；这不等于1099张逐一 UI 拉框、真实业务效率或模型支持。

T32真实渠道、原G4/性能及最终发行关卡保持原状态；未授权登录、模型调用、权重下载或业务图上传。Mask、视频、云端、公网部署、签名安装器不在此次范围。仓库仍 UNLICENSED，不授予再分发/商用许可。

[Label Studio 比较](label-studio-comparison.md)是其明确版本基线的历史分析，不倒写历史观察为本轮能力。选型须另做同条件性能、质量、操作者效率和合法授权核验。
